# Hackathon Cogna · RADAR

**RADAR · Inteligência de Engenharia**: protótipo front-end que mostra se a adoção de IA (Kiro + AI-DLC) está melhorando a engenharia da VP Tech em velocidade, qualidade e custo.

- [`radar/`](radar/): aplicação (Vite + React + TypeScript + Tailwind), com instruções em [`radar/README.md`](radar/README.md)
- [`radar-engenharia-spec.md`](radar-engenharia-spec.md): spec do protótipo

```bash
cd radar
npm install
npm run dev   # http://localhost:5173
```
